# Twist-TUI-rs
This is an open-source Terminal User Interface (TUI) for controlling, previsualizing, and automating Torsion Tests for a Mark-10's Automated Torque Tester ([TSTM-DC](https://mark-10.com/products/motorized-torque-testers/tstm-dc-tstmh-dc/)). This tool is written in [Rust](rust-lang.org) using the amazing [ratatui](ratatui.rs) library. Any issue report, comment, or contribution is welcome.

This project is currently a work in progress.
